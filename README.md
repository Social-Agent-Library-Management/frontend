## BookDuty
<img width="35%" alt="logo-on-brand" src="https://github.com/user-attachments/assets/7878f031-831c-431f-abe5-e9027d8ef7eb" />


사회복무요원으로 근무하며 기관 도서관을 관리하는 관리자 전용 웹 서비스의 프론트엔드입니다.

도서·소장본 등록, 대출 등록·반납 처리, 연체 관리, 엑셀 일괄 등록·내보내기, 대시보드를 제공합니다.
